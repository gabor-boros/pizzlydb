# M2 transactional graph core

This note records what was run in the working tree for Phases 1B and 1C. It is not a claim that the nightly soak passed.

## Ran

- `cargo test -p pizzlydb-core --lib --tests` covers the value codecs, the shared numeric order (`Int(2)` after `Float(1.5)`, `Decimal("1.50")` after `Int(1)`, `Int(1)` equal to `Float(1.0)`), and mutation round-trips including schema and namespace records.
- `cargo test -p pizzlydb-graph --tests` covers records, indexes, properties, the reference-model histories (`PIZZLYDB_PROPTEST_CASES`, default 1000), salvage, and `tests/lifecycle.rs`.
- Lifecycle tests check required properties at commit, label changes, one winner between a schema tightening and a violating write, detach delete, schema version once per transaction, resumable index build and drop, chunked namespace drop, exact counters across concurrent writers and a crash, and a full degree scan of a power-law graph.
- `verify_full` walks prefix scans one key at a time. It does not collect every node or edge id. Ready indexes are checked both ways. Building and dropping indexes are checked for entries that exist. Dropped indexes must have no entries.
- `cargo clippy -p pizzlydb-core -p pizzlydb-graph -p pizzlydb-txn -p pizzlydb-testkit --all-targets -- -D warnings` passed after the graph-model changes.

## Decisions

- [RFC 0001](../rfcs/0001-type-system.md) is accepted. Numbers share one index order. Names stay exact UTF-8 bytes. Over-long index keys are rejected.
- A node satisfies every label declaration. Tightening a declaration validates current members in the caller's transaction.
- Catalog names are never retired. Index ids and namespace ids are never reused. Dropped indexes and deleted nodes leave tombstones.
- Exact counters use `merge_add`. Degree and distinct-value samples are explicit maintenance calls. A sample that visits every member is marked exact.

## Not run

- 100,000 nightly histories for 14 consecutive nights.
- The 10-million-node index-build benchmark and the p99 latency bound.
- A filled namespace of one million entities for the drop. Chunking is tested on a small namespace and resumes after a crash in the index-build test.
- Isolation-suite nightly totals from [036](../roadmap/036-isolation-verification-suite.md) beyond the graph and transaction tests in this tree.
